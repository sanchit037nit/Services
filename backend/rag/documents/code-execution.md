# Code Execution

Codezy provides an online code execution feature.

Users can write source code using the Codezy code editor and select
the programming language they want to use.

Codezy currently supports C++, C, Java, Python and JavaScript.

When code is submitted, the backend sends the execution request to
the configured code execution service.

The execution service compiles and executes the submitted program.

The execution result contains information such as program output,
execution status and execution-related metadata.

The frontend displays the execution result to the user.
